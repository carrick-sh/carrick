# N1 Draft Work & Stale Draft PRs Triage (2026-10-10)

## Executive Summary & Architectural Context

This document provides a comprehensive, commit-by-commit triage of the N1 draft work in `carrick` across PR #59 (`work/n1-cm`, head `d81e1bf61`), PRs #11, #14, #16, #21 (`work/n1-p1..p4`), `triage/n1-files` (identical to `work/n1-cm`), and `triage/n1-files-g2-diag-0307`, along with a complete evaluation of the other 9 stale open draft pull requests (PRs #119, #52, #27, #28, #29, #31, #44, #66, #90).

Between the inception of the N1 branch series and current `main` (`09d8c7ddc`), Carrick underwent a fundamental architectural transformation:
1. **Shared-Kernel Inversion & Ring-First Flip** (PRs #104–#108, #120–#121, #128; `docs/design/arm-ring-first-flip.md`): Instead of trapping EL0 syscalls to hypervisor host threads that asynchronously communicate with guest EL1 via mailboxes and owner portals, execution is handled directly in-ring.
2. **Dual-Path Reality on Main**: Although the ring-first path is authoritative, **host ARM paths remain live and reachable on main** (`FamilyFallback` forwards, `perform_frame_cow` in `crates/carrick-vmm-hvf/src/trap/cow_engine.rs:3314`, `foreign_mm` observer reading in `crates/carrick-vmm-hvf/src/trap/foreign_mm/current_read.rs:188`, and host `owner_fork.rs:274`). These files still execute under certain fallback conditions until **Wave D** of the structural migration deletes them.
3. **Commit Census (212 Unique Commits)**:
   - **`DROP` (109 commits)**: Intermediate WIP checkpoints, diagnostic telemetry/probes (`n1g6`, `n1g5`), merge resolutions, and reverted experiments.
   - **`PORT` (39 commits)**: Real fixes and clean abstractions that still apply directly to live functions on main outside Wave D.
   - **`LIVE-UNTIL-WAVE-D` (31 commits)**: Fixes and tests targeting host ARM fork, COW engine, and foreign MM paths that remain live on main today, but which the director may elect to leave unported because Wave D deletes them. Detailed user-visible scenarios are provided for director decision.
   - **`RED-TEST` (18 commits)**: Lingering bug classes in filesystem, IPC, signal, and scheduler paths where dedicated red witnesses should be written or ported.
   - **`DIAGNOSTIC-DOC` (11 commits)**: Durable investigation plans, DTrace scripts, and diagnostic notes worth preserving in `docs/diagnostics/`.
   - **`OBSOLETE` (4 commits)**: Either already landed on main (`a2d3872a74` via PR #106; `0a8e22236b` and `d81e1bf613` via PR #128) or their target files were completely deleted (`fa9406d57b`).
