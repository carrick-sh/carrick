## Review fixes

Raw permit construction is crate-private again. The only bypass is an unsafe,
`host-test`-only fixture entry point with exact validation and custody obligations.
A peer-output compile-fail witness was red while the raw method was public, then
passed after sealing it. The preserved AM assertions and X1 now execute in the
standard host test recipe through `test-mm-owner`; registration text is not used
as an execution substitute.

All three new crates inherit workspace lints. Enabling them first produced ten
production panic errors. Core production now has no unwrap, expect, panic,
runtime assertion or allow attribute. Admitted generations are typed; invalid
source/spare/publication inputs return refusals. Copying rollback is licensed by
the single armed exclusive claim, which restores its Live phase. Grouped borrowed
venues and passive proposal inputs do not introduce another permit or cursor.

The review's non-fork COW completion-consumption delta is repaired. One shared
resolver body drains a resolved completion once, whether or not a fork sequence
exists; the native hook only reconciles a supplied parent completion. Its red
witness counted zero drains before repair and exactly one afterward. The fixture
checks consumption, not signed hardware COW execution.

The decoder receipt originally used `reservation_decoder_tests`, which selected
zero tests. The corrected `decoder_tests` command executes and passes all nine.
