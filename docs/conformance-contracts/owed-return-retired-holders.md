# Full owed-return table held by retired fork children (#1482)

`kernel.el1.anonymous-reservations` owns this case. Linux process exit releases
its private address space; a surviving parent's later anonymous retirement
cannot depend on the parent performing another fork.

The existing final-root retirement leaves resident returns owed until the
carrier's successful whole-MM release receipt. The settlement exclusion now
runs COW completions, the existing fork-quarantine drain, then bounded owed
returns. The quarantine owner still decides eligibility, frame release,
table hygiene and stock reuse. The excluded MM is not reclaimed, and a child
that remains published or installed stays quarantined. There is no second
frame-release or acknowledgement path.

A native venue's Stale answer does not prove a live foreign holder released
anything. While its exact notification source remains live, the full-table
drain returns a Reservations holder wait at the revision observed before the
attempt. The existing ring continuation enrolls, probes once, and releases its
execution capacity until the holder's release or retirement. A caller blocked
by HVF's host-served root MM 1 likewise waits for that root's host-boundary
reconciliation rather than classifying it as a retired native child.

The KVM fixture variant fills all 64 slots with eight holders, kills and reaps
them, and only then retires the parent's resident page. Native Linux must exit
zero; KVM must finish inside the existing 4096-exit budget without a later
fork. The HVF VM-free witness uses eight real ForkStock child transitions and
retired reservation journals, then calls the production exclusion sequence.
It requires eight inventory releases and no remaining quarantine. It models
physical inventory and descriptors; it does not claim execution of guest ARM
instructions or a signed artifact.
